# 英语训练舱 v1.0 成熟产品与极简 UI 落地计划

日期：2026-06-02

受众：产品、前端、后端、QA、发布负责人

## 1. 目标

把当前“可用 MVP”升级为可公开发布的 v1.0 学习应用。v1.0 的判断标准不是功能数量，而是用户能否稳定完成 CET-4 自学闭环，并且清楚知道每个结果来自什么证据、每个内容资源是否完整。

目标定位：

- 面向 CET-4 自学用户。
- 极简浅色学习工具，不做营销页、不做暗黑风、不做复杂装饰。
- 先保证可信、稳定、清爽，再做更复杂的 AI 个性化。
- 公开版本不内置来源不清的真题内容；真题只作为用户自有资料或已明确可用的本地资料处理。

v1.0 核心闭环：

```text
诊断 -> 今日计划 -> 自主专项 -> 复习 -> 阶段模考 -> 能力进展
```

任何页面都不能强迫用户只走单一路径。复习可以被推荐，但不能阻止用户进入语法、专项练习或模考。

## 3. 产品原则

### 3.1 可信优先

- 不把本地规则评分说成官方成绩。
- 不把 AI 参考答案说成标准答案。
- 不把浏览器朗读或 TTS 说成真题原音。
- 没有证据的能力项显示“待诊断/待训练”，不展示伪造分数。
- 缺资源时直接标注，不允许隐藏 404、死链接或误导性“已补上”。

### 3.2 用户可控

- 今日计划只推荐，不强制。
- 复习可提醒，但不能阻止专项练习。
- 语法、听力、阅读、词汇、写作、翻译、模考都必须能从专项或导航进入。
- 用户可以查看、导出、恢复本地学习数据。

### 3.3 极简表达

页面默认文案结构：

```text
标题
一句话说明
一个主操作
```

详细说明只放在折叠区、帮助入口或答后反馈中。

## 4. 信息架构

| 页面 | v1.0 角色 | 主操作 | 不应出现 |
| --- | --- | --- | --- |
| 登录 | 进入产品 | 登录/邀请码注册 | 长篇产品解释、功能宣传 |
| 今日训练 | 当天最短路径 | 开始今日首要任务 | 多组解释卡片、静态推荐 |
| 专项练习 | 自主选练 | 进入某个能力模块 | 大段教学说明、每卡多按钮 |
| 复习队列 | 主动回忆 | 开始复习 | 只看解析、不更新掌握度 |
| 阶段模考 | 阶段验证 | 标准模考 / 真题自练 | 真题和模拟混在同一卡片 |
| 真题自练 | 用户资料练习 | 打开页面版真题 | 外站裸链接、空卷、资源状态不明 |
| 能力进展 | 证据查看 | 查看弱项和趋势 | 无证据时显示假分数 |
| 设置 | 数据与发布合规 | 导出/恢复/隐私/反馈 | 隐藏关键数据风险 |

## 5. 极简设计系统要求

### 5.1 基础规范

统一以下组件，不允许每个页面单独拼视觉风格：

- 颜色：主色、文本色、边框色、浅底色、警示色、成功色。
- 字号：页面标题、卡片标题、正文、辅助文案、标签。
- 间距：页面内边距、卡片间距、按钮间距、表单间距。
- 圆角：按钮、卡片、输入框、标签统一。
- 状态：空状态、错误状态、加载状态、禁用状态、成功状态。

### 5.2 页面组件

| 组件 | 规则 |
| --- | --- |
| 主按钮 | 同一页面只保留一个最强主按钮 |
| 次按钮 | 只做返回、切换或打开辅助内容 |
| 卡片 | 标题、状态、进度、主操作，不放长解释 |
| 标签 | 用于资源状态、推荐原因、完成状态 |
| 空状态 | 说明为什么空、用户下一步做什么 |
| 错误状态 | 明确错误原因、恢复动作、是否影响学习 |
| 折叠区 | 放题库范围、评分规则、资源来源等长说明 |

## 6. 诊断可信评估

诊断不是官方考试分数，而是学习路径推荐依据。

### 6.1 出题

- 题目必须随机抽取。
- 同一用户下一次诊断不应直接重复上一套题。
- 诊断题答前不能展示中文辅助。
- 中文解释、句子翻译、解析只在答后展示。
- 未做题可以提交，但提交前要提示“有未完成项，结果置信度会下降”。

### 6.2 评分

评分分两层：

| 层级 | 用途 | 展示规则 |
| --- | --- | --- |
| 规则评分 | 选择题、客观证据、完成度 | 可写入稳定能力画像 |
| AI 评分 | 写作、翻译、口语等主观任务 | 只作为辅助判断，必须显示置信度 |

每个能力分必须展示：

- 分数。
- 证据来源。
- 置信度。
- 主要错因。
- 下一步建议。
- “非官方成绩，仅用于学习规划”的提示。

### 6.3 低置信度处理

- 主观题字数太少、录音缺失、未完成项太多时，结果标低置信度。
- 低置信度不能写入强结论，如“你一定薄弱”。
- 低置信度只能生成建议，如“建议补做语法/写作专项后复测”。

## 7. 专项练习与学习历史

专项练习必须记录真实学习历史，并影响下一次推荐。

### 7.1 记录对象

每次完成训练后至少写入：

- `PracticeSession`：本次训练会话。
- `Attempt`：每道题或任务的作答。
- `SkillProfile`：能力画像更新。
- `ReviewItem`：错题、低信心题、薄弱表达或复习项。

### 7.2 推荐规则

```text
优先未练题
-> 再优先错题和低信心题
-> 再按弱项安排题型
-> 题库耗尽后才允许回流旧题
```

用户重新进入专项练习时：

- 已练过的题不应无理由再次优先出现。
- 错题和低信心题进入复习或专项巩固。
- 题库耗尽时必须标注“题库已回流旧题”。

### 7.3 专项卡片

每张卡只显示：

- 模块名。
- 状态标签，如“今日推荐”“未练优先”“题库回流”。
- 进度，如“已练 8/40”。
- 一个主按钮。

## 8. 阶段模考与真题自练

阶段模考必须拆成两个入口：

| 入口 | 定义 | 行为 |
| --- | --- | --- |
| 标准模拟考试 | 按 CET-4 题型结构组卷 | 可作答、可提交、可生成阶段能力证据 |
| 真题自练 | 用户自有或本地扫描 PDF | 页面版展示、可练习、资源状态清晰标注 |

### 8.1 CET-4 标准模拟考试题型

模拟考试必须贴近 CET-4 结构：

- 写作。
- 听力理解。
- 阅读理解。
- 翻译。

不允许把非 CET-4 结构题型混入标准模拟考试并伪装成真题结构。

### 8.2 真题资源状态

每套显示出来的真题都必须标注：

- 可做。
- 可看。
- 有答案。
- 有音频。
- 仅浏览器朗读。
- 缺失资源。

规则：

- 不能出现外站裸链接。
- 不能出现空数据卡片。
- 没有答案就显示“缺答案”，不能说“已补上”。
- 没有官方音频就显示“无官方原音”，浏览器朗读或 TTS 只能标注为练习辅助。
- 页面版真题必须能打开并显示正文、题号、选项或明确无法解析原因。

## 10. 验收标准

### 10.1 产品验收

- 用户首次进入能完成诊断。
- 诊断结果包含分数、证据、置信度、建议和非官方声明。
- 今日训练能进入真实训练。
- 专项练习不会强制复习。
- 每个训练模块都能保存进度。
- 下次进入专项练习不会无理由重头开始。
- 真题区列表不为空，且显示的卷都可打开页面内容。
- 缺答案、缺音频必须直接标注。

### 10.2 UI 验收

- 登录页极简。
- 首页只突出今天最重要的一件事。
- 专项页是模块网格，不是说明书。
- 阶段模考中标准模考和真题自练分离。
- 同类按钮同样式。
- 同类卡片同结构。
- 同类错误同提示。
- 320px 宽度无横向滚动，按钮可点击。

### 10.3 技术验收

- 线上主要页面无 console error。
- 404 只允许作为显式用户可理解状态，不允许静默报错。
- 所有主要按钮真实点击测试通过。
- API/domain tests 通过。
- 生产 build 通过。
- 生产 smoke 通过。

## 12. 分阶段落地

### Phase 0：发布风险止血

目标：先消除误导和隐藏错误。

必须完成：

- 真题资源状态准确标注。
- 缺 AI 参考答案不再产生隐藏 404。
- 专项页明确显示学习历史记录规则。
- 诊断页明确非官方结果和置信度。

验收：

- API 测试覆盖缺失资源状态。
- 浏览器 smoke 不出现 console error。
- 专项练习持久化测试通过。

### Phase 1：极简 UI 收敛

目标：所有页面统一到极简学习工具风格。

必须完成：

- 登录页只保留必要输入和错误提示。
- 今日页压缩成一个主任务和少量辅助状态。
- 专项页统一模块卡片结构。
- 阶段模考拆清标准模考和真题自练。
- 设置页隐藏高级说明，默认只展示必要操作。

验收：

- 主要页面视觉截图通过人工审查。
- 移动端 320px 无横向滚动。
- 同类按钮、卡片、提示样式一致。

### Phase 2：诊断可信度升级

目标：让诊断结果可解释、可复测、不过度承诺。

必须完成：

- 随机题池策略。
- 答前无中文辅助。
- 漏答提交提示和置信度降级。
- 规则评分与 AI 评分分层展示。
- 每个分数展示证据和下一步建议。

验收：

- 诊断可靠性测试通过。
- 低置信度不会写入强结论。
- UI 明确显示“非官方成绩”。

### Phase 3：内容与资源闭环

目标：真题、模拟和专项内容不再出现空数据或错误承诺。

必须完成：

- 真题列表资源审计。
- 页面版解析失败状态。
- 答案/音频/朗读状态统一标签。
- 标准模考题型与 CET-4 结构一致。
- 真题自练可作答、可保存草稿。

验收：

- 内容资产测试通过。
- 显示出来的卷都可打开。
- 缺失资源全部显式标注。

### Phase 4：上架前发布能力

目标：达到公开应用市场最低发布标准。

必须完成：

- 隐私协议。
- 服务条款。
- 错误监控。
- 用户反馈入口。
- 生产 smoke。
- 全按钮 E2E。
- 回滚方案。

验收：

- 发布清单全部通过。
- 线上主流程无 console error。
- 回滚步骤可执行。
- 用户可理解数据存储和内容来源边界。
