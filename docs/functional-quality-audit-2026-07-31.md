## 本轮修复

1. 认证会话校验的临时网络失败不再清除有效 token；入口和设置页显示重试状态。
2. 阅读、听力、主观题、词汇和阶段模考只在完成记录确认写入后清除草稿，并阻止重复提交。
3. 主观题 AI 反馈写入草稿，缓存清理或刷新后可恢复评分、评语和参考答案。
4. API 客户端对 HTML/非 JSON 网关错误给出稳定的服务器错误提示。
5. 复习记录保存失败时不再错误显示“复习已完成”。
6. 成员账号的高级控制台文案与所有者权限分开，所有者专属内容、邀请、聚合观测仍隐藏。
7. 全按钮审计在异步完成弹窗出现较晚时会先清理弹窗并重试导航，避免审计脚本误报。

## 第二轮产品设计与功能审计

| 风险项 | 修复与验收 |
| --- | --- |
| 完成状态早于服务器确认 | 服务器同步失败会向训练组件抛出错误；页面、答案、反馈和草稿均保留，可在原页重试 |

| 移动端导航入口缺失 | 补齐设置、帮助及前后导航控制；390px 截图确认按钮不覆盖标签、导航可完整到达 |
